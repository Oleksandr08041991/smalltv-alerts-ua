# SmallTV Air Alerts UA — план реалізації

Цільовий пристрій: GeekMagic SmallTV Ultra (ESP-12F / ESP8266, 4 MB flash, ST7789 240×240).

## Збережені можливості
- Тематичні годинники та їхнє налаштування.
- Авіарадар, Home Assistant (MQTT), Claude Usage, сповіщення.
- Wi-Fi, вебінтерфейс, яскравість/нічний режим, OTA.
- Не використовувати `smalltv_lean` для основної збірки: там вимкнено частину вказаних можливостей.

## Оптимізація ESP8266
- `WITH_TICKER=0` у `env:smalltv`: фінансовий модуль вилучено зі збірки.
- `build_src_filter` виключає `features/ticker/*`.
- `Settings.ticker` та пов'язані функції серіалізації не збираються за вимкненого модуля.
- У вебінтерфейсі модуль приховується за `features.ticker=false`.
- Додаткова оптимізація HTML/CSS/JS та перевірка пам'яті — після компіляції.

## Air Alerts (наступний етап)
- Новий `DisplayMode` `alerts`, окремий пункт вебменю та каруселі.
- API: `https://api.alerts.in.ua/v2/iot/active_air_raid_alerts/{uid}.json`.
- За замовчуванням UID=14 — Київська область; UID=31 — місто Київ.
- `R` — тривога, `Y` — попередня загроза, `P` — часткова тривога, `N` — відсутність тривоги.
- Помилки, тайм-аут, 401/429 і застарілі дані не можуть відображатися як «Без тривоги»: окремий стан «Немає даних».
- API-токен вводиться через захищену вебформу пристрою, НЕ зберігається у GitHub; налаштування не повинні повертати токен клієнту.
- Інтервал опитування від 30 секунд, рекомендовано 60 секунд; дотримуватись лімітів API.
- Виведення статусу та часу останнього підтвердженого оновлення.
- За бажанням — пріоритетні сповіщення на початок/відбій з поверненням до попереднього режиму.
- Зберігати всі звичайні режими роботи прошивки.

## Перед установленням
1. Зібрати `pio run -e smalltv`; перевірити залишок Flash/RAM і запас OTA.
2. Запустити тести, перевірити сумісність повної збірки.
3. Підготувати відновлення заводської прошивки; перед записом рекомендується повний UART-бекап 4 MB.
4. Для SmallTV Ultra перше встановлення через двоетапний OTA loader, не напряму великим образом.
5. Не прошивати пристрій до проходження перевірок; саморобний індикатор не замінює офіційні сповіщення.
