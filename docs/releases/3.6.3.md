# SmallTV Air Alerts UA 3.6.3

## Відображення без мерехтіння
- Вбудовані годинники більше не очищають увесь екран кожної секунди.
- Аналоговий циферблат змінює лише стрілки; цифрові — лише змінені цифри.
- Після повернення з повідомлення або втрати синхронізації годинник коректно перемальовує повний екран один раз.
- Спливні повідомлення малюються один раз на подію, без повторного очищення дисплея.
- Карта перемальовується лише коли змінилися статуси або актуальність даних.

## Покращення карти
- 27 регіонів відображені кольоровими зонами з внутрішніми межами.
- Маркер вибраного регіону та зрозуміла легенда.
- Схематичне зображення: **це не точна географічна карта адміністративних меж**.
- За відсутності актуальних даних усі області сірі.
- Збережені українське меню, чотири годинники та безпечне зберігання API-токена.

## Перевірки
- GitHub Actions: PlatformIO ESP8266 / smalltv + loader — зелена збірка.
- Регресійний тест: заборонено повноекранне очищення в регулярному оновленні годинника/карти.
- Розмір образу поміщається в OTA-слот із запасом.
- Потребує перевірки на фізичному GeekMagic: збірка не імітує LCD-контролер.

## OTA
Після публікації релізу пристрій на 3.6.2 відкриває «Система → Check Update» й може завантажити `smalltv-mod-firmware.bin` із GitHub Releases.

У разі збою залишається ручне OTA через /update. Не встановлювати лоадер повторно.
