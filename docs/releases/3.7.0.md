# SmallTV Air Alerts UA v3.7.0

## Зміни

- **Біла карта України:** спрощені контури реальних областей (Natural Earth Admin-1), тонкі межі, світлі регіони без тривоги, жовтий — попередня загроза, червоний — повітряна тривога, оранжевий — часткова. Автономні сповіщення лишаються у вибраній області. Геометрія приблизна, не офіційні адміністративні межі.
- **Анімований авіадруг:** маленький доброзичливий дрон/літачок із рухом крил, похитуванням, морганням, зміною настрою та анімованим ротом. Текст у великій комікс-бульці, автор унизу дрібніше.
- **100 українських фраз:** 5 коротких літературних уривків, 25 адаптованих бізнесових думок Франкліна із позначкою «переказ» і 70 авторських мотиваторів. Режими: змішаний, робочий, загальний. Локальна добірка і жести змінюються залежно від місяця, години та черговості; нові тексти будуть надходити через майбутні OTA-релізи, не окремо з інтернету.
- **П'ятий циферблат — авіаційний висотомір.** Циферблат є годинником, не приладом висоти.
- **Збережено:** інші годинники, .stheme, повідомлення про тривоги, українське меню, вебналаштування токена і регіону.
- **Вимкнено для ESP8266:** біржа/криптовалюти, Radar, Home Assistant, Clawdmeter.
- **Менше мерехтіння:** локальне перемальовування змінених частин, статусна карта змінюється лише на події.
- **OTA:** оновлення ставиться в чергу з вебменю, наступне завантаження виконує TLS-перевірку релізу й скачування до SNTP/інших мережевих сервісів, щоб мати більше суцільної RAM. Образ релізу публікується під стандартним іменем `smalltv-mod-firmware.bin`.

## Перевірки перед випуском

- GitHub Actions `Build SmallTV Ultra`: тести проти мерехтіння та перевірки персонажа/карти/текстів, PlatformIO ESP8266 firmware і recovery loader, обмеження розміру OTA-слота.
- Реальний 240×240 екран, HTTPS API і OTA від **3.7.0 до наступної версії** поки потребують тесту на пристрої. Збірка не гарантує відсутності апаратних проблем.

## Встановлення

1. Для встановлення 3.7.0 зі старої 3.6.3 спробуйте вебменю `Система → Check Update → Update now`. Механізм старої прошивки може ще показати «not enough heap» — у такому разі встановіть основний `smalltv-mod-firmware.bin` через ручну сторінку `/update`; **лоадер не потрібен**.
2. Перезавантажте пристрій і перевірте карту, циферблати, авіадруга та доступ до вебменю.
3. Наступна версія після 3.7.0 використовуватиме полегшений холодний OTA-механізм; якщо він не спрацює, передайте точне повідомлення з вебінтерфейсу.
