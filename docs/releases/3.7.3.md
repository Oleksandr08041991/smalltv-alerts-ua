# SmallTV Air Alerts UA v3.7.3 — літак, 140 фраз і новий OTA

## Анімований «Авіадруг» тепер літак
- Персонаж перероблений із квадрокоптера на маленький **літак із помітними несучими крилами**, хвостовим оперенням, кабіною, носовим обтічником і колесами; рот, очі, усмішка, нахил, підскоки й зміна настрою залишилися.
- Замість тисяч окремих операцій `drawFastHLine` для кожного кадру дисплей отримує **готові 4-рядкові RGB565-блоки** через `draw16bitRGBBitmap`. Знижується хвильове построкове мерехтіння. Блок складається з нової пози персонажа на тлі чорного, без попереднього стирання героя.
- Обидві тривалості для «Авіадруга» (фраза 60 с / прогулянка 30 с за замовчуванням) налаштовуються в українському вебінтерфейсі. Карусель має незалежний таймер цитат.
- Герой повністю вміщується в дисплей 240×240 під час руху по внутрішньому периметру; маленький герой у комікс-бульці не перекриває її нижній край.

## Банк мотиваційних висловів
- **140 фраз**: 5 коротких класичних літературних рядків, 25 переказів ідей Франкліна, 70 власних коротких висловів та 40 нових коротких перефразувань за темами двох наданих українських добірок [Всеосвіта](https://vseosvita.ua/blogs/50-motyvatsiinykh-tsytat-107542.html) й [Depositphotos](https://blog.depositphotos.com/ua/tsitati-pro-uspih.html).
- Немає безособового підпису «Оригінальна фраза»: авторські вислови підписані «Авіадруг». Прізвища для адаптованих ідей відображаються окремо, помітнішим шрифтом, із маленьким чесним уточненням «ПЕРЕКАЗ».
- Текстовий банк та адресний індекс перенесено в **PROGMEM** для зменшення використання оперативної пам'яті ESP8266. Читається через `memcpy_P` і `strncpy_P`.

## Нове оновлення по Wi-Fi — без TLS на ESP8266
- **Причина:** бібліотека BearSSL для GitHub Release API/CDN вимагала великі TLS-буфери, тоді як ESP8266 має близько 80 КБ сумарної RAM і ще менше вільної RAM в активному застосунку. Саме це створювало повторювані «low heap» та «not enough heap».
- **Нове рішення:** кнопка «Перевірити оновлення» у вебінтерфейсі відкриває GitHub Releases API **безпосередньо у браузері** користувача (CORS доступний). «Оновити зараз» завантажує відповідний firmware образ із версіонованого файлу на нашому окремому публічному GitHub `ota`-branch через CDN jsDelivr (із резервним raw.githubusercontent.com). У браузері перевіряються версія, розмір і заголовок образу, а де браузер підтримує WebCrypto — також SHA-256. Далі браузер передає байти в ESP8266 по Wi-Fi через наявний `POST /update`.
- Відсутній небезпечний сторонній CORS-проксі; тільки GitHub і jsDelivr над **публічним образом**. Браузер сам має доступ в інтернет і до локального IP пристрою. Секретний токен alerts.in.ua не покидає GeekMagic.
- За потреби ручне оновлення залишається доступним. Під час START вручну та автоматично звільняються тимчасові кеші режимів, щоб 4-КБ буфер Updater виділявся на ESP8266 надійніше.
- GitHub Actions спершу перевіряє збірку й програмні тести, а при явному релізному коміті публікує **той самий образ** в окрему `ota`-гілку за унікальним шляхом `firmware/vX.Y.Z.bin` та в GitHub Releases.

**Увага:** для переходу зі старої версії (де Check Update все ще виконує важкий HTTPS-запит на ESP8266) перше встановлення 3.7.3 потрібно виконати вручну — через вкладку «Ручне оновлення» і `smalltv-mod-firmware.bin`. З версії 3.7.3 наступні оновлення використовуватимуть кнопку у вебінтерфейсі. Без виконаного тесту на реальному GeekMagic не можна гарантувати роботу OTA на всіх браузерах або відсутність артефактів LCD.

## Перевірки
- `node tests/mascot/test_aviation_release.js`
- `node tests/alerts/test_display_refresh.js`
- `bash tests/update/run.sh`
- `node tests/update/test_browser_ota.js`
- PlatformIO smalltv, smalltv_loader, OTA slot headroom ≥8KB

**Фінальна перевірка перед публікацією:** усі чотири регресійні групи пройшли, PlatformIO ESP8266 та loader зібрані успішно. Автоматичний реліз публікує такий самий перевірений `smalltv-mod-firmware.bin` в GitHub Releases і гілці `ota`, призначеній для браузерного завантаження. Цей факт не замінює перевірку на фізичному дисплеї.
