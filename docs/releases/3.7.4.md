# v3.7.4 — browser-assisted OTA without GitHub Releases dependency

## Підстава
Під час релізу v3.7.3 Actions зміг успішно опублікувати `ota/firmware/v3.7.3.bin`, але GitHub Release creation повернув 403 «Resource not accessible by integration». Тому кнопка перевірки оновлень не повинна залежати від GitHub Releases. Інший старий дефект: сам ESP8266 мав недостатньо heap для HTTPS GitHub API і CDN.

## Виправлення
- OTA-перевірка запускається у браузері користувача через публічний GitHub Contents API:
  `https://api.github.com/repos/Oleksandr08041991/smalltv-alerts-ua/contents/latest.json?ref=ota`.
- Браузер читає Base64 JSON із `version`, `size`, `sha256`, `file`. Відхиляє неправильні імена образів, розміри та синтаксис.
- Браузер завантажує `https://cdn.jsdelivr.net/gh/Oleksandr08041991/smalltv-alerts-ua@ota/firmware/vX.Y.Z.bin` (із резервним `raw.githubusercontent.com`) та завантажує файл в ESP8266 через same-origin `POST /update` з індикатором відсотків.
- Жодний великий TLS-буфер у ESP8266 при цьому не створюється. Локальний OTA-шлях на пристрої звільняє тимчасові буфери перед Flash Update.
- Успішні компіляції публікуються з GitHub Actions у версіоновані шляхи окремої гілки `ota`; GitHub Releases залишається **додатковою необов'язковою дзеркальною публікацією**.
- Прошивка v3.7.3 у гілці `ota` лишається доступною як історичний образ, але новий механізм перевірки входить у v3.7.4.

## Інші зміни, включені з v3.7.3
- Впізнаваний маленький літак замість квадрокоптера, без окремих роторових дисків.
- Плавніше малювання великими 4-рядковими RGB565 плитками, а не тисячами построкових SPI викликів.
- **140 коротких українських висловів**, із бізнесовими і мотиваційними переказами на основі [Всеосвіта](https://vseosvita.ua/blogs/50-motyvatsiinykh-tsytat-107542.html) і [Depositphotos](https://blog.depositphotos.com/ua/tsitati-pro-uspih.html); справжні автори показуються чіткіше, авторські підписані «Авіадруг».
- Понад 4 КБ заощадженої статичної RAM завдяки зберіганню текстів у PROGMEM.

## Початкове встановлення
Через стару непрацюючу кнопку Check Update на пристроях v3.7.2 і раніше **v3.7.4 потрібно один раз встановити вручну**:
1. У GitHub відкрити гілку `ota`, файл `firmware/v3.7.4.bin`; завантажити його (це тільки основна прошивка, не лоадер).
2. Вебменю GeekMagic → «Система → Ручне оновлення (OTA)» → вибрати `v3.7.4.bin` → відправити та дочекатися перезапуску.
3. Подальші версії перевіряти кнопкою «Перевірити оновлення → Оновити зараз». Браузер повинен одночасно бачити інтернет і локальну адресу GeekMagic.

## Перевірки
CI: збірка PlatformIO ESP8266; перевірка 4KB ручного OTA; симуляція браузерного Check Update за OTA-маніфестом з Base64, валідації образу та POST /update; тести каруселі, анімації, шрифту й карти. Це не замінює тест на фізичному GeekMagic; плавність ST7789 і проходження CDN у конкретному браузері перевіряються після встановлення.
